KEY DECISION: Web files (HTML/CSS/JS)
HTML files open in the existing Preview iframe. A console interceptor script is injected into the iframe that captures console.log/warn/error and runtime exceptions, then PostMessages them to the TerminalPane below. This way web code and server code both show output in the same terminal strip.
