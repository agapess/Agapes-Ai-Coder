AI CORE
1

AI Auto-Fix Loop

Code runs → error detected → Claude fixes it → re-runs. Zero user action. Keep looping until it works or Claude gives up with an explanation in plain English.

2

AI Project Planner

Before writing code, AI shows a simple plan: "I'll build X with Y. It will do A, B, C. Sound good?" Non-technical users confirm before generation starts. Prevents wasted runs.

3

Plain-English Explainer

After every generation or error, AI explains what it built (or broke) in simple terms. No jargon. "Your app couldn't start because a library is missing. I'm installing it now."

4

AI Auto-Tester

After building, AI writes and runs tests automatically. Catches bugs before the user even sees the app. Shows a simple "✓ 12 tests passed" badge.

INPUT SUPERPOWERS
5

Voice-to-App

Speak your idea into the microphone. AI transcribes and builds. Perfect for non-technical users who find typing intimidating. Uses Web Speech API (no extra service needed).

6

Screenshot / Image-to-App

Upload a screenshot or photo of an app you like. Claude's vision analyzes it and clones the design. "Make me something like this" — and it does.

7

URL Clone

Paste a website URL. AI scrapes its design and functionality, then rebuilds it from scratch as editable code in FORGE. Great for "I want something like Airbnb but for X."

MCP TOOLS FOR AI
8

Web Search MCP

AI can search the web during code generation to look up current APIs, documentation, and packages. No more hallucinated library names. Claude finds the real, working version.

9

Browser Testing MCP (Playwright)

AI controls a real browser to test the generated web app. Clicks buttons, fills forms, checks output. "I verified your todo app — adding, completing, and deleting items all work."

10

GitHub MCP

Push projects to GitHub with one click. AI writes the README, commits everything cleanly, and creates the repo. Non-technical users get a real GitHub presence automatically.

11

Package Manager MCP

AI can install npm, pip, cargo packages directly during the build loop. No more "install X first." AI handles dependency installation as part of the auto-fix loop.

SHARING & DEPLOY
12

One-Click Deploy

Publish any app to the web instantly — Vercel, Netlify, or Railway. Non-technical users get a real public URL to share with anyone. No accounts or config needed (uses FORGE's credentials).

13

App Gallery / Templates

Browse a gallery of pre-built app templates. One click to fork and customize. Also lets users publish their apps so others can clone and remix them.

14

Export as Desktop App

Wrap any app as an Electron desktop app or PWA with one click. Users get an installable .exe or Mac app from their FORGE project. No build knowledge needed.

POWER FEATURES
15

Full Multi-LLM Support

Switch between Claude, OpenAI (GPT-4o), Google Gemini, Ollama, LM Studio, and any OpenAI-compatible API from the settings panel. Per-project model selection.

16

Multi-Agent Build

For complex projects, spawn multiple AI agents in parallel: one builds the backend, one the frontend, one writes tests. They merge into one project. 3x faster for large apps.

17

Version Time Travel

Every successful run is snapshotted automatically. Slider in the UI lets you jump back to any working version. "Go back to how it was 3 steps ago" — one click.

18

Live Collaboration

Share a FORGE session with someone else. Both can prompt the AI simultaneously. Great for teaching — show a student how to build something in real time.
