FORGE Superapp — Full Roadmap

18 features grouped into 5 phases. Each phase ships independently and builds on the last.

PHASE 1
Sandbox + AI Loop + Multi-LLM
Foundation — everything builds on this
🖥 Code Execution Sandbox
node-pty + xterm.js + WebSocket. Full terminal inside FORGE. Auto-detect any language.
🔄 AI Auto-Fix Loop
Run → error → Claude fixes → re-run. Loops until working. Zero user action needed.
💬 Plain-English Explainer
Every action explained in simple language. No jargon. Beginner-friendly status messages.
🤖 Full Multi-LLM Support
Claude, OpenAI, Gemini, Ollama, LM Studio, any OpenAI-compatible API. Unified settings panel.
📦 Package Manager MCP
AI installs npm/pip/cargo deps automatically. Part of the fix loop — no manual installs.
⏱ Auto-Run on Generate
Code runs the moment generation finishes. Non-technical users never need to click Run.
PHASE 2
AI Intelligence Layer
Makes the AI smarter and builds trust
📋 AI Project Planner
Plan before code. AI shows what it will build, user confirms. Fewer wrong-direction builds.
🧪 AI Auto-Tester
AI writes + runs tests after building. "✓ 12 tests passed" badge for confidence.
🔍 Web Search MCP
AI searches web for real APIs, docs, packages during generation. No hallucinated libraries.
⏪ Version Time Travel
Auto-snapshot every working version. Slider to jump back. "Undo" for entire app states.
PHASE 3
Input Superpowers
Build from anything — voice, images, URLs
🎤 Voice-to-App
Speak your idea. Web Speech API transcribes. AI builds. Zero typing needed.
📸 Screenshot-to-App
Upload any screenshot. Vision AI clones the design as working code.
🌐 URL Clone
Paste a URL. AI scrapes and rebuilds it. "Make something like Twitter but for X."
🎭 Playwright MCP
AI controls real browser to test the web app. Clicks, fills forms, verifies behavior.
PHASE 4
Share & Deploy
Get apps into the world
🚀 One-Click Deploy
Vercel / Netlify / Railway. Public URL in seconds. No accounts needed for user.
🖼 App Gallery
Browse templates. Fork + customize. Publish your own for others to remix.
💾 Export Desktop App
Wrap as Electron .exe or PWA. One-click installer for any FORGE project.
🐙 GitHub MCP
AI writes README, commits cleanly, creates repo. Non-technical users get a GitHub profile.
PHASE 5
Advanced Power
For scale and teams
⚡ Multi-Agent Build
Parallel Claude agents: backend + frontend + tests simultaneously. 3x faster for complex apps.
👥 Live Collaboration
Share a session. Multiple users prompt AI simultaneously. Real-time teaching and pair building.
