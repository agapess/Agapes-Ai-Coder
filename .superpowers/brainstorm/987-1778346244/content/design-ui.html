▶ Run button
Lives in the file tab bar, right side. Shows detected language (e.g. "python") next to it. Disabled for unsupported types.
↕ Resize handle
Drag to adjust code vs terminal split ratio. Terminal can be collapsed to 0 height when not needed.
● Exit status
Green "exit 0" = success. Red "exit 1" = error. Shown in terminal header after process ends.
